
# Практична робота
## Тема: Оброблення текстових файлів
### Варіант 6

## Мета роботи

Отримати практичні навички створення та оброблення текстових файлів мовою Python.

## Умова завдання

Розробити програму, яка:

1. Створює текстовий файл TF6_1.txt із символьних рядків різної довжини.
2. Читає вміст файлу TF6_1.txt та формує рядки за правилом:
   - якщо рядок коротший за 20 символів, він доповнюється пробілами;
   - якщо рядок довший за 20 символів, він обрізається до 20 символів.
3. Записує оброблені рядки у файл TF6_2.txt.
4. Читає вміст файлу TF6_2.txt та виводить його на екран по рядках.

## Структура проєкту

- `main.py` — головний файл запуску програми.
- `create_file.py` — створення початкового текстового файлу.
- `process_file.py` — оброблення текстових рядків.
- `display_file.py` — читання та виведення результатів.
- `test_project.py` — автоматичне тестування програми.
- `TF6_1.txt` — початковий текстовий файл.
- `TF6_2.txt` — файл з обробленими даними.

## Використані технології

- Python 3
- Модуль unittest
- Текстові файли
- Обробка помилок try-except

## Запуск програми

Для запуску програми необхідно виконати команду:

```bash
python main.py
```

## Запуск автоматичних тестів

Для перевірки правильності оброблення рядків необхідно виконати:

```bash
py -3 -m unittest -v test_project
```

## Результати тестування

У програмі реалізовано три автоматичні тести:

1. Перевірка доповнення короткого рядка пробілами.
2. Перевірка обрізання довгого рядка до 20 символів.
3. Перевірка рядка, довжина якого становить рівно 20 символів.

Усі три тести успішно пройдено.

## Висновок

Під час виконання практичної роботи було розроблено програму мовою Python для створення та оброблення текстових файлів.

Реалізовано створення початкового файлу TF6_1.txt, оброблення символьних рядків відповідно до заданої умови та запис результатів у TF6_2.txt.

Для коротких рядків реалізовано доповнення пробілами, а для довгих — обрізання до 20 символів.

Також реалізовано обробку помилок відкриття файлів за допомогою конструкції try-except та автоматичне тестування програми.

Поставленої мети практичної роботи досягнуто.
