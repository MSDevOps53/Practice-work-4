Практична робота №4 — варіант №3
Тема: Оброблення текстових файлів у Python.

Файли програми:
main.py          — об'єднує усі частини завдання.
create_file.py   — частина а), створення TF4_1.txt (тімлід).
process_file.py  — частина б), підрахунок слів і створення TF4_2.txt (учасник 1).
display_file.py  — частина в), читання та виведення TF4_2.txt (учасник 2).
test_project.py  — автоматичні тести для перевірки.
TF4_1.txt       — приклад початкового файлу (створюється автоматично).
TF4_2.txt       — приклад результату (створюється автоматично).

Запуск: python main.py
Тести:  python -m unittest test_project.py -v

Як обробляються слова:
- Пробіли і розділові знаки відокремлюють слова.
- Підраховуються всі входження слів, у тому числі повторні.
- Для кожної довжини від 1 до 16 виводиться один приклад слова та загальна кількість.
- Якщо слів певної довжини немає, виводиться «немає» та кількість 0.
- Слова довші за 16 символів спричиняють повідомлення про помилку.

Пропонований розподіл роботи в команді:
- Тімлід: create_file.py і main.py, створення репозиторію, злиття Merge Requests.
- Учасник 1: process_file.py, гілка feature/count-words.
- Учасник 2: display_file.py, гілка feature/display-result.

Важливо: програма створює два .txt файли в поточній робочій директорії.
